# AgentOS 三栏面板拖动调整设计

## 目标

为工作区页面的两个左侧栏分隔边界增加拖动调整宽度功能，同时保证聊天区始终保留足够空间，避免输入框、模型选择、思考设置、中断按钮和发送按钮重叠或错位。

## 范围

支持以下两个分隔边界：

1. 工作区导航栏与会话历史栏之间。
2. 会话历史栏与聊天区之间。

右侧执行详情栏不增加拖动功能，现有响应式隐藏规则保持不变。宽度不持久化，刷新页面后恢复默认值。

## 交互设计

- 分隔边界显示窄的垂直拖动手柄，鼠标悬停时显示可调整宽度的光标和轻微高亮。
- 使用 Pointer Events 支持鼠标和触摸拖动。
- 拖动期间暂时禁止页面文字选择，并在拖动结束时清理全局指针事件和选择状态。
- 左栏宽度默认 `240px`，可调整范围为 `180px–360px`。
- 会话历史栏宽度默认 `256px`，可调整范围为 `180px–420px`。
- 拖动时根据容器当前宽度计算聊天区可用空间；若继续拖动会使聊天区小于最小宽度，则将宽度限制在边界，不允许继续挤压聊天区。
- 在现有小屏响应式规则下，隐藏的会话历史栏及其分隔手柄不参与布局。

## 实现结构

### `apps/web/src/app/workspace/[id]/page.tsx`

- 增加两个面板宽度状态。
- 增加仅供当前页面使用的拖动处理逻辑：记录起始指针位置和起始宽度，计算目标面板宽度，并按最小/最大范围及聊天区最小宽度进行限制。
- 在 `AgentList` 与 `ConversationHistory` 之间、`ConversationHistory` 与 `ChatPanel` 之间渲染拖动手柄。
- 保持现有数据加载、会话切换、消息发送和执行状态逻辑不变。

### `apps/web/src/components/chat/AgentList.tsx`

- 接收可选宽度样式或宽度属性。
- 继续负责工作区导航内容，不在组件内部管理拖动状态。

### `apps/web/src/components/chat/ConversationHistory.tsx`

- 接收可选宽度样式或宽度属性。
- 继续负责历史会话内容，不在组件内部管理拖动状态。

### `apps/web/src/app/globals.css`

- 添加拖动手柄的基础样式、悬停/拖动状态和触摸行为。
- 不改变已有聊天输入框窄容器换行规则。

## 稳定性约束

- 所有可变宽度面板必须保持 `min-width: 0`，聊天区继续使用 `flex: 1` 和 `min-width: 0`。
- 拖动手柄使用固定的 `flex: 0 0` 宽度，不通过负边距覆盖相邻内容，避免边界变化造成内容错位。
- 宽度计算以实际三栏容器宽度为准，不使用浏览器 viewport 代替面板容器宽度。
- 拖动结束、组件卸载或指针取消时必须移除全局监听器。

## 验收标准

1. 两个分隔手柄均可用鼠标拖动，拖动后对应面板宽度随指针移动。
2. 触摸拖动可用，且不会触发页面整体滚动或文字选择。
3. 两个面板均不能超出设计的最小/最大宽度。
4. 聊天区不会被压缩到导致输入框控件重叠的宽度；输入框在空闲和运行中状态都保持对齐。
5. 折叠或展开思考进度后，拖动后的布局仍保持对齐，无横向溢出。
6. 小屏幕现有响应式行为不回归。
7. 前端构建、单元测试和浏览器交互验证通过，控制台无新增错误或警告。

## 非目标

- 不增加右侧执行详情栏的拖动调整。
- 不增加宽度持久化、用户设置或后端接口。
- 不引入第三方拖拽或面板布局依赖。
