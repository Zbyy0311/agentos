## 17. TaskRunService

11 项公开职责全部实现：`createTask`、`createRun`、`createLegacyRunForBridge`、`cancelQueuedRun`、`startRunForBridge`、`completeRunForBridge`、`failRunForBridge`、`cancelRunForBridge`、`acceptRun`、`cancelTask`、`reopenTask`；另有仅 Bridge 内部路径使用的 `compensateLegacyClaimFailure` 与 `compensateTerminalSaveFailure`（无 HTTP API）。全部跨 Aggregate 操作经同一 SQLite handle 的短事务；Bridge 创建 Run 前在同一事务内检查 archived/blocked/done/cancelled 与 active Run；不执行 AgentRunner、不管 Process、不写 `agent_runs`、不扫描 recovery。T50–T67 通过。

## 18. Unified Terminal Reconciliation

`resolveTaskAfterRunTerminal` 为唯一终态归并规则，`cancelQueuedRun`、`compensateLegacyClaimFailure`、`failRunForBridge`、`cancelRunForBridge`、terminal JSON save 补偿五条路径全部经它：pending 存在 → Task 保持 `in_progress` 且指针/accepted/completedAt 保留；无 pending 且无 active Run → `open`；completed → 写 `pending_result_run_id`；绝不扫描历史 completed Run 恢复指针。T111–T113、T118–T120 通过。

## 19. Acceptance Window

`acceptRun` 同事务校验：Task `in_progress`、pending 非空、候选 Run completed、同 Task/Workspace、无 active Run；允许接受较早 completed Run（T114）；accept 后 Task `done` + `accepted_run_id` + `completed_at`，清 pending；reopen 清三字段且历史 completed Run 不恢复 window（T115/T116）；只有新 Run 进入 running 才重回 `in_progress`（T117）。错误码：`TASK_NO_ACCEPTANCE_WINDOW`、`RUN_NOT_COMPLETED`、`TASK_HAS_ACTIVE_RUN`、`TASK_NOT_FOUND`、`RUN_NOT_FOUND`、`INVALID_TASK_TRANSITION`、`VERSION_CONFLICT`。
