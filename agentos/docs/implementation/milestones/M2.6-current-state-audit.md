## 6. Implementation Approach Comparison

| | A: single large M2.6 covering every mutation | B: Task-domain v2 idempotency + existing version-guard completion | C: generic Idempotency Foundation first, then Task/Run and Approval integrations |
|---|---|---|---|
| Blast radius | very large; touches Legacy/Approval at once | small; canonical v2 only | medium; foundation isolated, integrations staged |
| Compatibility | highest regression risk | Legacy/Conversation untouched | same as B if integrations staged |
| Transaction boundary | unclear per-aggregate | clear: extend TaskRunService transactions | clear: foundation owns record+mutation atomicity |
| Testing | hard to gate incrementally | maps to existing v2 suites | foundation unit tests + integration suites per phase |
| M2.7/M3 boundary | risks entangling cutover | clean; M2.7 untouched | clean; foundation reusable by later milestones |
| Future Approval persistence | forces premature decision | defers cleanly (OD-17) | foundation reusable if Owner later adds Approval |

**Recommendation: Approach B**, with the C-style foundation built inside P1/P2 as the internal shape (repository + service), but with integration strictly limited to Task-domain v2 operations approved by Owner Decisions. Approval remains pending OD-17; Legacy remains excluded.

## 7. Recommended Implementation Phases (proposal only — not authorization)

- **P1 — Schema, Types and Repository**: Migration 010 (`idempotency_records`), `IdempotencyRecord` shared type, canonical request fingerprint, `IdempotencyRepository` (insert/lookup/integrity).
- **P2 — Idempotency Service**: key validation, fingerprint comparison, atomic execute/replay inside `runInTransaction`, stable error codes, corrupted-record fail-closed.
- **P3 — Task-domain Integration**: Create Task, Create Run, Cancel Run, plus only operations explicitly approved by Owner (Accept/Cancel/Reopen candidates). Idempotency lookup must precede active/state guards.
- **P4 — Optimistic Concurrency API**: per OD-15/OD-16 (optional `expectedVersion` or If-Match, conflict mapping, compatibility for existing callers).
- **P5 — Final API, Security and Compatibility Review**: no-leak review of stored results, full gates, docs closure.
- **P4-Approval or separate milestone**: only if OD-17 includes Approval; not included by default.
