## 5. ULID Algorithm

- 26-character Crockford Base32 (no I L O U)
- Timestamp: ms since 2024-01-01, 48-bit big-endian
- Randomness: 10 bytes from `crypto.randomBytes`
- Same-ms monotonicity: XOR sequence counter into random bytes
- Clock regression: uses last-seen timestamp
- No external dependencies (node:crypto only)
- Injectible clock and random source for testing

## 6. Version Convention

- Version starts at 1 (`INITIAL_VERSION`)
- Each successful update increments by exactly 1
- `VersionConflictError` (`code: 'VERSION_CONFLICT'`) when stale
- `assertVersionedMutation` returns next version (expectedVersion + 1)
