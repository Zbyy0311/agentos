## Decision template

Each entry contains:

- Decision: the question requiring owner disposition
- Options: the materially different choices
- Recommendation: conservative planning guidance
- Rationale: evidence-bound reason
- Risk: principal failure mode
- Reversibility: expected ability to undo
- Required Evidence: evidence needed before approval
- Owner Status: state field
