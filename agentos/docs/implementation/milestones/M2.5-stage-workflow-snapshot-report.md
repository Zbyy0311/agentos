## 5. API Contract

The existing `GET /api/workspaces/:workspaceId/v2/runs/:runId` endpoint is extended additively.

Default response:

```json
{
  "run": {},
  "snapshotAvailable": true,
  "snapshotSchemaVersion": 1
}
```

The existing `run` shape is not modified. Without `include`, the response contains no `snapshot`, `stages`, `contentHash`, Snapshot row ID, or workflow row metadata.

`include=snapshot` adds an explicit `RunSnapshotPayloadV1` DTO and top-level `contentHash`.

`include=stages` adds an explicit `RunStage[]` DTO.

`include=snapshot,stages` and `include=stages,snapshot` return both sections. Pre-M2.5 Runs return `snapshotAvailable=false`, `snapshotSchemaVersion=null`, `snapshot=null` when requested, `contentHash=null` when requested, and `stages=[]` when requested.

No new Snapshot, Stage, or Details endpoint is introduced.

## 6. Include Parser

`parseV2RunInclude()` accepts only one string query value. It supports the case-sensitive tokens `snapshot` and `stages`, comma separation, trimming, order independence, and duplicate deduplication. Empty tokens, bare `include=`, unknown tokens, wrong case, arrays, objects, repeated query values, and `include[]=snapshot` fail with `VALIDATION_FAILED`.

## 7. DTO and No-Leak Boundary

`buildV2RunDetailResponse()` reconstructs Snapshot payload, Workflow Stages, Agent fields, Provider fields, and RunStages through explicit allowlists. It does not spread repository rows or payloads. Returned values are detached from repository objects.

The API layer validates content hashes, workspace-relative working directories, sensitive headers/cookies/tokens/assignments/flags, split-equals argument forms, placeholders, secret/environment references, and private-key markers. Unsafe values fail with `RUN_SNAPSHOT_FAILED` without exposing the rejected literal, SQLite details, paths, stacks, commands, arguments, or hash inputs.

## 8. Error Mapping

The v2 boundary maps:

- `AGENT_NOT_AVAILABLE` → HTTP 409, `Agent is not available`
- `PROVIDER_CONFIG_NOT_AVAILABLE` → HTTP 409, `Provider configuration is not available`
- `WORKFLOW_NOT_AVAILABLE` → HTTP 409, `Workflow is not available`
- `RUN_SNAPSHOT_FAILED` → HTTP 500, `Run snapshot creation failed`

Unknown errors remain `500 { "error": "Internal server error", "code": "INTERNAL_ERROR" }`.
