## Phase A — Quarantine exact-source idempotency

The migration Registry Repository now exposes an explicit `findQuarantinedByExactSource` lookup alongside the existing completed exact-source lookup. Both the Workspace adoption service and the Legacy Task import service apply the same contract:

- completed exact source: no-op (unchanged semantics)
- quarantined exact source: no-op; no new Attempt and no new Backup
- failed exact source: retryable; the failed row is preserved and a new Attempt is reserved
- changed source hash: fresh classification; a changed rejected source produces a new Quarantine Attempt
