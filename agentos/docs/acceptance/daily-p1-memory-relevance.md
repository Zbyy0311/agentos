# P1 记忆相关性与版本纠错

执行入口使用 `memory-relevance.v2`。管理列表和未指定新策略的旧检索接口保留原有行为。执行先核验范围、敏感内容、状态、有效期和已报告错误的具体版本，再判断词项或受门禁约束的语义相关性，最后分配预算。无匹配允许空正文；固定规则单独记录 `fixed-default`。

中文采用 NFKC 规范化和二字词项，常用英文术语有显式别名。追加迁移 049 建立派生索引，按条目版本、正文哈希、切分版本重建；索引故障回退到相同词项匹配并记录 `lexical-fallback` 和降级状态。049 不搬迁旧记忆，也不补造旧快照。

`wrong` 反馈只隔离历史选择指向的版本。反馈针对 v1 而当前已是 v2 时，不隔离 v2。共享全局条目的错误报告对所有有权使用该条目的工作区生效；一个报告被驳回不解除其他待处理报告。每次调用已经冻结的正文、版本和哈希继续保存。

解决反馈须同时携带工单和条目版本，选择修正、归档或重新验证，并提交结论与依据。追加迁移 050 保存解决依据，条目、版本审计、工单、事件一起提交，任何写入失败都回滚。人工修正文案的权威标识为 `user-explicit`，不能继承旧内容的 `system-verified`。不含解决依据的旧 `status: resolved` 请求返回 409 和明确升级提示；旧驳回请求继续支持。

96 条固定查询保持原样。CI 的独立 memory-relevance 作业要求 16 条无匹配查询非固定误选为零、中文精确词项命中至少 12/16、recall@5 不低于旧 FTS 基线；同时检查秘密过滤、版本冲突、事务回滚和 canonical 快照重放。测试向量只证明缓存和排序路径，不能写入生产质量收据。真实 embedding 必须通过新策略、当前语料和模型版本对应的门禁；旧语义收据保留但不授权新策略。

验收证据分为三类：提示词捕获测试、隔离本地服务与真实界面（模拟 Provider）、真实 Windows Provider。每类须绑定冻结提交与命令退出码；前两类不能替代真实模型或已有项目迭代收据。历史 Lite 收据保持原样。
